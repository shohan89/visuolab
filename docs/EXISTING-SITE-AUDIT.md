# Visuolab — Existing Static Site Audit

Source of truth: `referance-website/` (plain HTML, CSS and JS; no build step). This document is read-only analysis. No source file was modified or deleted.

Per-page tables in section 3 and the asset table in section 6 were generated by script from the HTML. The remaining sections come from reading every CSS and JS file in full.

## 1. Summary

| Item | Count / value |
|---|---|
| HTML pages | 23 (5 top-level, 8 case studies, 4 services, 6 articles) |
| CSS files | 6 (about 1,950 lines, no preprocessor) |
| JS files | 4 (`main.js` 405 lines, `hero.js`, `mesh.js`, `scene.js`) |
| Asset files | 28 (about 3.4 MB; largest: `showreel.mp4` 1.6 MB, `earth.webp` 476 KB) |
| Broken internal links | 0 |
| Missing image/video/poster files | 0 |
| External origins | `fonts.googleapis.com`, `fonts.gstatic.com`, `cdn.jsdelivr.net` (Lenis, Three.js) |
| Forms | 2 real-looking (contact page: contact form, plus footer newsletter on every page). Neither submits anywhere |
| Cache-busting | `?v=182359` on every CSS, JS and image reference |

Notes on what the numbers hide:

- The nav, mega menu, CTA band and footer are copy-pasted into all 23 pages. The footer includes 7 award badges and an SVG `<symbol id="laurel">`.
- There is no `/services` overview page. The "Services" nav item is a `<button data-menu>` that only opens the mega menu (comment in `base.css`).
- Two sections on every service page are present in the HTML but carry the `hidden` attribute: "What we fix" (`.prob-sec`) and the inline CTA band (`.band-sec`). Source comments say "remove the hidden attribute to bring it back". Treat them as optional, switchable content.
- Footer "Industries" links, "Privacy policy", "Cookie policy", "Terms" and all four social links point to `#`.
- The footer newsletter form is `onsubmit="return false"`. The contact form is intercepted in `main.js` and only shows a success message.
- `about.html` has an unused `.team-grid` rule in `about.css`, but no team markup (team section was removed from the page).

### 4.2 `js/hero.js` (home only) — hero scroll animation

- Target: each `.scroll-sequence > .banner.reaching`. Section height is `280svh`; the banner is `position:sticky`.
- **Progress:** `-section.top / (section.height - innerHeight)`, clamped, smoothed with a critically damped follow (`1 - exp(-dt/95)`).
- **Phases:** `cycle = progress*5.6`. 0–3.2 approach (`--reach`, smoothstep). 3.2–5.6 contact: `--pulse` (decaying sine bump) and `--ripple` / `--ripple-opacity` for the contact ring.
- **Pointer parallax:** `pointermove` on the banner sets `--mx/--my` (−1…1) with a 190ms exponential ease. Reset on `pointerleave` / `pointerup`.
- **Idle drift:** `--float = sin(now/2300)*6px`.
- **Star field:** if `.stars` is empty, generates 48 `<i>` with golden-ratio positions, 3 sizes, per-star glow, opacity, duration (5–11s) and negative delay.
- **Performance:** rAF loop starts and stops with an IntersectionObserver (`rootMargin:'25%'`).
- **Reduced motion:** all variables forced to 0 (static pose).

### 4.3 `js/mesh.js` (home only) — WebGL mesh gradient

- Creates a `<canvas class="mesh-canvas">` inside `.mesh`, adds `has-gl`. Context: `webgl`, alpha, no antialias, premultiplied alpha. Falls back to `experimental-webgl`. If no GL or shader compile/link fails, removes the canvas and the CSS gradient (`mesh-flow` keyframes) stays.
- Fragment shader: domain-warped fbm (5 octaves, two warp passes), 4-colour palette (deep navy, brand violet, blue, light), vignette and vertical fade, output premultiplied alpha. Pointer shifts the vignette slightly.
- Single full-screen triangle. DPR capped at 1.5. `ResizeObserver` for sizing, IntersectionObserver and `visibilitychange` to pause. Reduced motion renders one frame.

### 4.4 `js/scene.js` (About only) — 3D scene

- ES module with an importmap: `three@0.170.0` and `three/addons/` from jsDelivr (in the HTML, not in JS).
- Scene: transparent canvas, ACES tone mapping (1.1), `PMREMGenerator` environment from a procedurally painted studio canvas, 2 directional and 2 point lights.
- Object: `ParametricGeometry` twisted band (300×40 segments, 200×28 on ≤900px), `MeshPhysicalMaterial` with transmission 1, thickness 1.2, ior 1.5, dispersion 5, clearcoat. Geometry is re-evaluated every frame (`reshape(t*.35)`).
- Refraction trick: a backdrop plane that only renders into the transmission buffer (`onBeforeRender` toggles `colorWrite`), so no halo appears on screen.
- Reacts to pointer (tilt) and `scrollY` (roll). Pauses off-screen and when the tab is hidden. One frame under reduced motion. Whole init is wrapped in try/catch and hides the host on failure.
- Needs to be served over HTTP (the README notes it does not work from `file://`).

## 9. Accessibility and robustness observations

- `prefers-reduced-motion` is honoured in CSS (11 blocks) and in all four JS files.
- The hero has `role="img"` and an `aria-label` describing the hands and orb. Decorative images use empty `alt`; decorative SVG uses `aria-hidden`.
- Mega menu works on `:hover` and `:focus-within`. Mobile menu is a real dialog with focus trap and Escape handling. Accordions and the tooltip buttons use `aria-expanded`.
- `<form>` success uses `role="status"`.
- Content is hidden until `.in` is added by JS (opacity 0). With JS disabled, `.reveal` content stays invisible. There is no `<noscript>` rule.
- No skip link, no OG/Twitter/canonical/structured-data tags, no `sitemap.xml`, no `robots.txt`, no favicon link.
- Contact form and newsletter input have `aria-label`/labels; the newsletter input has only `aria-label`.
- Videos: showreel is `muted autoplay loop playsinline` with `aria-hidden="true"` on its container.

## 10. Migration risks specific to this codebase

1. **Class-for-class markup fidelity.** Many rules depend on exact DOM shape (`:nth-child`, adjacent siblings, `.stair-bar:hover .stair-tip`, `.reveal-group`). JSX must reproduce the HTML 1:1.
2. **Global CSS order.** The six files override each other; keep them global and in the same order.
3. **One-shot JS.** `main.js` assumes one page load. In a client-routed app every observer, listener, interval and the Lenis instance needs setup/teardown per mount.
4. **Text-node mutation** (manifesto) and **innerHTML builders** (clocks, share, mobile menu) conflict with React.
5. **Pinned hero** reads `section.offsetHeight` and `getBoundingClientRect()` every frame; it depends on Lenis scroll and `280svh` height.
6. **Scroll-driven CSS** (`animation-timeline`) relies on `@supports` fallbacks; do not refactor.
7. **Three.js** is browser-only and large; load only on `/about`, client-side, with the existing try/catch fallback.
8. **Hard-coded counts** in filter chips and stats must be derived from data.
9. **Pre-hydration invisibility:** `.reveal` starts at opacity 0.
10. **Placeholder content:** alt text, image credits, fake forms and `#` links need client decisions.
